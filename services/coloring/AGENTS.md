# Отдельный Python-генератор

- Это самостоятельный проект для отдельного поддомена. Не интегрировать существующий
  модуль раскрасок, каталог маркеров, пользователей или БД Artmate без нового запроса.
- Прочитать README.md и ARCHITECTURE.md перед изменениями. Учитывать корневой AGENTS.md.
- Внутренние domain/application не импортируют адаптеры, Pillow, OpenCV, Shapely или I/O.
  Сборка вычислений — в `delivery/cli.py`, HTTP/worker — в `studio/adapters`.
  Проверки границ — `tests/test_architecture.py`.
- Площади относятся к финальному печатному масштабу и измеряются интегралом кубических
  кривых. Не путать мм² с шириной. Соседние области используют общие границы.
- Сохранять локальные seeds и повторяемость. Не вызывать глобальный RNG seed.
- Шрифт строго `fonts/Arial/arialmt.ttf` внутри пакета; не заменять системным Arial.
- Все символы одного размера и без поворота, контуры/символы `#898989`.
- Сортировка палитры выполняется до назначения 1–9/A–Z. Белые не занимают символ,
  не нумеруются и не дробятся для номера. Политики определены в `palette.py` и `typography`.
- Production entrypoints — `coloring-api` и `coloring-worker`; одноразовый CLI — `coloring-generate`. Не подключать диагностические writers
  к delivery, не сохранять все этапы, не переносить outputs/исходники/кэши в репозиторий.
- Сохранять manifest последним. Не перезаписывать существующие результаты и не чистить
  чужие/активные каталоги. Квоты, TTL и lease контролирует SQLite repository; worker выполняет очистку.
- Python 3.13. Фиксированные runtime/build/dev зависимости — `requirements-*.txt`.
  Это не Yarn workspace. Не добавлять Python-зависимости в package.json/yarn.lock.
- Проверки: `python -m pytest -q`, `ruff check .`, `ruff format --check .`.
  При изменении упаковки собрать wheel и выполнить `scripts/verify_install.py` после установки.
- Docker build context — корень монорепозитория. Проверять `docker compose -f
  services/coloring/compose.yml config --quiet` из корня. Не заявлять проверку образа,
  если Docker daemon недоступен.
- Не коммитить, не выполнять SSH и не развёртывать на VPS без соответствующей авторизации.

- Проект — книга, источник принадлежит странице. Готовые проекты и принятые версии не имеют TTL.
- Резерв результата выделять на claim, не на enqueue всей книги. Один running на весь том.
- Повторная нумерация заменяет оформление без запуска векторизации; ZIP содержит снимок принятых страниц.
- Миграции схемы транзакционные и сохраняют исходники. Не добавлять старые HTTP aliases.

- Готовые мелкие детали помечены Cell.prefilled: не сливать, не делить, не нумеровать.
  Белые/близкие к белому готовые детали сохраняют контур, включая границу с цветной
  готовой деталью. Заливки должны рисоваться до контуров; внутри белого не добавлять
  новые разрезы и символы.
  Пользовательский минимум площади действует только для незакрашенных областей.
  Не превращать детали в растровую картинку или наложение поверх символов.
- После изменения поведения генератора обновлять ALGORITHM_VERSION и проверять,
  что пересчёт старого алгоритма не перезаписывает принятую версию автоматически.

- Локальные обученные модели разрешены пользователем. Веса фиксированы по revision/SHA-256,
  скачиваются `scripts/prepare_models.py` при установке/сборке, не во время задания.
- Модель работает в отдельном CPU-процессе и завершается до векторизации. Не передавать ей
  секреты, не добавлять runtime-сеть и промежуточные файлы. Соблюдать лимит worker 2 ГиБ.
- При отсутствии уверенных ориентиров сохранять обычную защиту деталей. При ошибке установки
  модели не выдавать результат за успешно выполненную обработку с распознаванием.

- Для пропущенных профилей требовать согласованные обнаружения разных поворотов и
  уверенный ориентир носа. Не защищать произвольный bbox и не придумывать глаз/рот
  по слабым ориентирам. ProfileRegion задаёт только место анализа исходных цветов.
- Дополнительные профили соблюдают общий бюджет готовых деталей; вне подтверждённых
  зон прежняя обработка сохраняется. Не вращать исходник или печатный результат.
