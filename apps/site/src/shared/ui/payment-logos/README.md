- `tbank.svg`: оригинальный SVG из [той же Figma](https://www.figma.com/design/OJMlWhh4LkIB4h3AWBo3K6/?node-id=261-416), вариант `dark=no, fit=yes, icon=no`, 118 × 36 px. Контуры и цвета обоих экспортов сохранены. Источник — выбранный пользователем community-пакет.
- `mir.png`: оригинальный `Logo Mir RGB-01.png` (600 × 600 px) из [официальных рекламных материалов НСПК](https://nspk.ru/advertising), архив `logo.zip`. Цветной знак на прозрачном фоне. Файл сохранён без изменений; CSS ограничивает видимую область исходного PNG (100, 243)–(500, 357), масштабируя её до 36 × 10.26 px.

- `sbp.svg`: компактный цветной знак с официального [сайта СБП](https://sbp.nspk.ru/business), [исходный SVG](https://sbp.nspk.ru/storage/settings/common/logo_mobile/5e648604-f95d-472d-afe2-33b856f345ed.svg). Геометрия и цвета сохранены. Надпись «СБП» рядом — подпись интерфейса, не перерисованный логотип.
- `dolyame.svg`: официальный [брендбук Долями](https://brand.tbank.ru/docs/Бренд/Долями/Logo/), файл `RUS/SVG/dolyami-logo-black.svg` из связанного архива. Векторные контуры сохранены; `viewBox` ограничен видимой областью вместо большого поля исходного файла.

Подготовленный бейдж в способах оплаты: [Figma, `179800:10742`](https://www.figma.com/design/hv0vvLR2QAhGz29p3RoHnB/?node-id=179800-10742), вариант `S 18`, размер 126 × 18 px.

`PaymentLogo` явно передаёт исходный `viewBox` каждому SVG: стандартная оптимизация SVGR удаляет его у файлов с совпадающими `width`/`height`. Без этого уменьшенный знак СБП обрезается вместо масштабирования.

В выборе банка используется `size="compact"`: Долями 84 × 12 px, Ozon Банк 100.48 × 16 px, Т-Банк 78.67 × 24 px, знак СБП 17.15 × 20 px с подписью 12 px. Все знаки выровнены по центру строки; пропорции исходных векторов сохранены.
