# Макет просмотра палитр

Изолированная демонстрация на `/coloring-palette-preview`; без API-записей и изменений рабочего просмотра. Метаданные страницы запрещают индексацию.

Изображение исходника и контур взяты из пользовательского архива `собачки_зип.zip`, файлы `svg/Frame.svg` и `outline/Frame.png`. Область рисунка — SVG viewBox `37 28 538 760`; нижняя печатная легенда не включена в область просмотра.

`artmate-demo.webp` — демонстрационное перекрашивание исходного SVG по `lib/sample.ts`. Оттенки маркеров взяты из ранее подготовленной таблицы выкраски, но соответствия областям выбраны только для демонстрации переключения. Это НЕ утверждённая палитра альбома. В интерфейсе есть предупреждение; нельзя переносить эту фикстуру в production-данные.

Один просмотрщик переключается между режимами «Контур / В цвете» и «Оригинал / выбранная палитра». У каждого режима своё положение ползунка, которое восстанавливается при возвращении. Смена палитры не выключает сравнение: справа всегда выбранная версия, в том числе оригинал. Образцы цветов и номера материалов также берутся из выбранной палитры. `previewPalettes` в `lib/sample.ts` связывает название, изображение, цвета и опцию выбора; новые палитры добавляются туда без отдельной логики сравнения. Ползунки на изображении и под ним синхронизированы. Второго изображения и автопрокрутки нет. Тёмная палитра, печатный альбом, работы участников и пояснение о цвете расположены под картинкой, как на текущей странице.

Блок работ переиспользует `CommunityWorks`. В route гидратируется снимок публичного списка для «Собачки», №1: GET `https://api.artmate.ru/club/colorings/cifrovaya-raskraska-sobachki/01/works` 2026-09-27 вернул `[]`. Поэтому показано настоящее пустое состояние, а не выдуманные работы. Это фиксированный снимок для локального макета, не живое подключение production. Никакие работы, настройки аккаунта и пользовательские данные не сохраняются.
