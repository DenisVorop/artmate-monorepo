# Шрифт скидки

`unbounded-discount.woff2` — Unbounded 600 с символами `−0123456789%`.
Используется только для числа скидки. Русские надписи используют общий шрифт сайта.

Источник: [Google Fonts](https://fonts.googleapis.com/css2?family=Unbounded:wght@600&display=swap&text=%E2%88%920123456789%25).
Лицензия — [SIL Open Font License 1.1](./OFL.txt).

Если для числа скидки понадобятся другие символы, обновите набор через параметр
`text` Google Fonts и сохраните полученный WOFF2 в этот файл.
