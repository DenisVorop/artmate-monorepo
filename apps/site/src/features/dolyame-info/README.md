# Долями на сайте

Информационные виджеты в карточке товара и корзине открывают общее пояснение. Покупатель выбирает `tbank_acquiring` при оформлении заказа, затем выбирает Долями в существующей форме Т-Банка. Виджеты не создают платежи и не выбирают банк автоматически.

Варианты оформления заказа:

- Т-Банк: Мир, СБП, Долями.
- Ozon Банк: Мир, СБП.

## Адаптации содержания

Не показываем пример «0 ₽ сегодня», вычисленные части платежа или переключатель сроков из демонстрационного макета: доступные покупателю условия определяются на стороне формы банка. Вместо графика — шаги оплаты через Т-Банк. В заголовке корзины — «Оплата Долями». Высота окна зависит от этого текста; исходные 652/578 px не задаются искусственно. В узком контейнере текст переносится и увеличивает высоту виджета.

В окне используется логотип Долями вместо исходного кросс-логотипа с Т-Банком. На мобильном SF Pro берётся из системного шрифта Apple; на других платформах используется fallback. Эти адаптации и сборка круглого знака не являются подтверждённой копией макета пиксель в пиксель.

## Приёмка

Проверить переключение обоих банков, сохранение выбора после открытия/закрытия пояснения, клавиатурное закрытие и возвращение фокуса. Проверить размеры 320, 375, 768, 1024 и 1360 CSS px, отсутствие горизонтального переполнения, переносы логотипов и мобильное окно.

Для окончательной проверки pixel perfect нужны оригинальные SVG подготовленных знаков и PNG компонентов из Figma. Экспорт в текущем браузере не возвращал файл; сравнение через overlay/diff пока не выполнено. Текущий код — реализация с проверенными выше измерениями, с перечисленными адаптациями, а не прошедшая такую приёмку версия.

2026-10-02: компоненты проверены в изолированном локальном предпросмотре с настоящим `PaymentMethodField` и React Hook Form. На 320, 375, 768, 1024 и 1360 CSS px `scrollWidth` совпадал с `clientWidth`. Проверены оба банка, все три точки открытия пояснения, закрытие крестиком и Escape, возврат фокуса к триггеру и сохранение выбора банка. Исправлено смещение мобильного окна из-за независимого CSS-свойства `translate` базового диалога. Полные страницы с данными backend и сравнение пикселей Figma этим тестом не покрыты.

Выбор банка находится в шаге 03 «Способ оплаты», после доставки. Логотип банка — слева, знаки Мир, СБП и Долями — справа. Согласия находятся в правой карточке заказа, под итоговой суммой. Промокод и баллы раскрываются отдельно. Согласия связаны с формой получателя через `form`, ошибка создания заказа появляется рядом с кнопкой оплаты. На мобильном карточка находится после доставки, нижняя кнопка сохранена.

Локальный предпросмотр с настоящими `BaseCheckoutFlow`, `OrderSummary` и RHF, тестовым расчётом и обработчиком без запросов: оба банка передаются при отправке, обязательные поля и согласия проверяются, до расчёта доставки обе мобильные кнопки отключены. Пояснение Долями сохраняет выбранный банк; промокод раскрывается без вложенных форм. Ширины 320–1360 CSS px проверены повторно. Скриншоты — `outputs/dolyame-ui-20261002/checkout-sidebar-desktop.jpg` и `checkout-sidebar-mobile.jpg`. Реальный платёж и серверный расчёт этим предпросмотром не проверялись.
