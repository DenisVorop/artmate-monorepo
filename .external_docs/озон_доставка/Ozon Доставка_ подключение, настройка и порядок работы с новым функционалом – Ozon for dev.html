Ozon Доставка: подключение, настройка и порядок работы с новым функционалом

6 ноября 2025
55710
13 мин
85

Подключение Ozon Доставки открывает возможность продавать товары со своего сайта или приложения, используя логистическую инфраструктуру Ozon.

Для этого достаточно подать заявку в личном кабинете, создать частное приложение, настроить доступ для разработчика и интегрировать API. После успешной интеграции вы сможете расширить каналы продаж, сохраняя все преимущества платформы Ozon. 

Подключение Ozon Доставки

1. Перейдите во вкладку «Товары» → «Приложения» → «Ozon Доставка».

2. В карточке приложения «Ozon Доставка» вы найдете краткое описание функционала. Рекомендуем ознакомиться со списком требований к продавцу. Для работы с Ozon Доставкой необходимо:

  • Быть продавцом из России и работать на схемах FBO и/или FBS;
  • Торговать одновременно на Ozon и на своей площадке.

3. Нажмите кнопку «Подключить».

4. После этого вы будете перенаправлены во вкладку «Анкета». Здесь необходимо указать контактные данные и ответить на вопросы.

5. Нажмите кнопку «Далее».

Затем заполните информацию о вашем магазине, прикрепите логотип и нажмите «Подключить». Название и логотип магазина будут отображаться в личном кабинете покупателя, позволяя ему определить интернет-магазин, где был оформлен заказ. Ссылка на магазин необходима для перехода покупателя на ваш сайт и выполнения операций с заказом, например, отмены.

  • После успешного заполнения данных приложение «Ozon Доставка» будет со статусом «Проверка данных».
  • Мы обработаем вашу заявку в течение 5 рабочих дней. В случае успешной проверки статус изменится на «Подключено». Ваша заявка также может быть отправлена на доработку или отклонена с обоснованием. Важно: после отклонения заявки повторная подача возможна через 24 часа.

После успешной проверки данных вы получите доступ к методам, позволяющим использовать логистику Ozon через частное приложение. Это даст вам возможность продавать товары со своего сайта и доставлять их с помощью Ozon.

Создание частного приложения

Для интеграции с методами Ozon Доставки, которые доступны через OAuth-авторизацию, вам потребуется создать частное приложение. Вы можете настроить его самостоятельно или предоставить доступ к настройкам вашему разработчику.

Процесс создания частного приложения:

  • Войдите в личный кабинет продавца.
  • Перейдите в раздел «Настройки», затем в подраздел «Приложения и разрешения».
  • Нажмите кнопку «Создать».

Введите название приложения, например «Ozon Доставка», и выберите роли, необходимые для работы с методами Ozon Доставки.

Перечень доступов (скоупов), необходимых для работы с Озон Доставкой:

1. Seller-api.ozon-logistics – создание/отмена заказов, работа с картой, проверка доступности доставки и др.

2. Seller-api.posting-fbo – получение FBO поститнгов.

3. Seller-api.posting-fbs – получение FBS постингов.

4. Seller-api.returns – получение возвратов FBO и FBS.

5. Seller-api.report – получение отчетов.

6. Seller-api.product – получение информации по товарам.

Вы можете также использовать другие доступы, если в этом есть необходимость.

Более подробную информацию о методах Ozon Доставки можно найти в этой статье.

Доступность доставки Ozon для ваших покупателей

Чтобы определить, доступна ли вашему покупателю доставка Ozon, необходимо проверить возможность получения заказа. Для этого воспользуйтесь методом v1/delivery/check, передав номер телефона покупателя в установленном формате.

География доставки:

  • Пункты выдачи заказов (ПВЗ): Покупатель может выбрать точку самовывоза на карте в любой момент с помощью метода v1/delivery/map. Обратите внимание, что этот метод не проверяет доступность и сроки доставки до покупателя.
  • Вы можете сохранить список доступных ПВЗ для самостоятельной отрисовки на вашей стороне с помощью метода v1/delivery/point/list.
  • Информацию о конкретной точке доставки можно получить через метод v1/delivery/point/info.
  • Курьерская доставка: Возможность курьерской доставки можно проверить только при наличии выбранного товара, используя метод v2/delivery/checkout.

Рекомендации:

Рекомендуется предоставлять покупателю выбор способа и точки доставки на этапе оформления заказа или в корзине. В противном случае, для минимизации нагрузки и оптимизации количества запросов к API, создавайте кэш данных на своей стороне.

Оформление заказа (проверка наличия товара и расчет сроков доставки)

Важно! После создания заказа его состав нельзя изменить или отредактировать. Перед подтверждением заказа тщательно проверьте наличие всех товаров и сроки их доставки.

Поскольку товары в заказе могут храниться на разных складах и иметь различные сроки доставки, необходимо определить количество и состав сборочных заданий (сплитов) для каждого склада Ozon.

Для этого используйте метод v2/delivery/checkout, передав в него список товаров и информацию о выбранном способе доставки (схему доставки FBO/FBS, ID пункта самовывоза или адрес для курьерской доставки).

В ответ вы получите информацию о возможности доставки до выбранной точки (самовывоз или адрес), расчетные сроки доставки и детализированный состав заказа, разделенный по отправлениям.

Обработка заказа

Создание заказа в системе Ozon возможно только после подтверждения оплаты покупателем.

Для инициирования сборки заказа используйте метод v2/order/create. Обратите внимание, что успешный ответ (статус 200) не гарантирует создание заказа, так как могут возникнуть различные причины для отказа (например, отсутствие товара).

Заказ должен быть оформлен на покупателя, данные которого подтверждены методом v1/delivery/check. Если покупатель указывает в качестве получателя третье лицо, его данные необходимо внести в поля получателя (recipient). Если покупатель является и получателем, его данные следует продублировать.

При создании заказа формируются логистические контейнеры (постинги), содержащие товары. Таким образом, заказ состоит из постингов, а постинги — из товаров. Ozon может изменить состав созданного заказа и постингов, если часть товаров не была подобрана.

Способы доставки

Для Ozon Доставки доступны два способа доставки:

  • Самовывоз (pickup): Покупатель самостоятельно забирает товар из пункта выдачи заказов. При создании заказа необходимо указать идентификатор точки самовывоза в структуре pickup.
  • Курьерская доставка (courier): Курьер Ozon доставляет товар по указанному адресу. При создании заказа в этом случае необходимо передать адрес получения и координаты в структуру courier.

Отслеживание заказа и постингов

Для FBO отправлений используйте методы:

  • v2/posting/fbo/list для получения списка всех отправлений FBO.
  • v2/posting/fbo/get для получения подробной информации о конкретном отправлении FBO.

Для FBS отправлений используйте методы:

  • v3/posting/fbs/list для получения списка всех отправлений FBS.
  • v3/posting/fbs/get для получения подробной информации о конкретном отправлении FBS.

Получение списка кодов маркировки товара

Для получения списка кодов маркировки “Честный знак” подобранного товара используйте метод v1/posting/marks. Этот метод возвращает экземпляры и маркировки товара, которые были подобраны в постинге, после того как он достиг статуса "Ожидает отгрузки". (только для FBO отправлений)

Особенности работы метода:

  • Частичная выдача: При частичной выдаче товара будут заполнены соответствующие поля с идентификаторами экземпляров. Это позволит вам определить, какие маркировки не нужно выводить из оборота.
  • После поступления в логистику Ozon: После того как товар поступит обратно в логистику Ozon, в ответе останутся только выданные маркировки.
  • Использование с v1/posting/marks: В этот метод следует передавать только те постинги, которые были получены с помощью метода v2/order/create.

Отмена заказа

Внимание! Процесс отмены асинхронный. Возвращайте денежные средства покупателю только после подтверждения отмены.

Для отмены всего заказа или его части используйте следующие методы:

1. Получение списка возможных причин отмены:

  • Общий справочник причин: v1/cancel-reason/list
  • Список причин отмен конкретного заказа: /v1/cancel-reason/list-by-order
  • Список причин отмен конкретного отправления (постинга): /v1/cancel-reason/list-by-posting

2. Проверка доступности отмены: v1/order/cancel/check

3. Выполнение отмены:

  • Отмена заказа целиком: v1/order/cancel
  • Отмена части заказа (постинга): v1/posting/cancel

4. Проверка статуса отмены:

  • Статус отмены заказа: v1/order/cancel/status
  • Статус отмены отправления (постинга): v1/posting/cancel/status

Особенности отмены для FBS: Отмена отправлений FBS осуществляется стандартными методами, описанными в документации Ozon: ссылка на раздел документации.

Важно! Методы получения списка причин отмены (для заказа или постинга) следует использовать только при фактической необходимости такой проверки. Избегайте получения этого списка "заранее" без соответствующего запроса пользователя.

Заказы, оформленные с помощью методов Ozon Доставки, могут быть аннулированы в следующих случаях:

  • Ozon отменил заказ до его прибытия в пункт выдачи или до доставки покупателю по внутренним причинам (если выбран FBO).
  • Покупатель не забрал заказ.
  • Покупатель отказался от получения заказа при его получении — полностью или частично (такая ситуация также называется невыкупом).
  • Покупатель инициировал отмену заказа через сайт/приложение продавца.

Важно! Покупатель не может отменить заказ через личный кабинет Ozon.

Возврат товара

Отслеживать возвраты вы можете с помощью метода v1/returns/list. Обратите внимание: если покупатель забрал товар и решил вернуть его после получения, он не сможет сделать это через Озон. В этом случае ему необходимо связаться напрямую с продавцом.

Остатки

Для эффективного планирования поставок и оценки количества остатков используйте метод v1/analytics/stocks. Этот метод не предназначен для отображения доступных к продаже остатков.

Чтобы показать покупателям количество товаров, находящихся на складах продавца, используйте метод v4/product/info/stocks.

Мы настоятельно рекомендуем тщательно отслеживать количество остатков и своевременно пополнять их. Создание заказов с помощью методов Ozon Доставки будет невозможно при отсутствии зарегистрированных в Ozon остатков.

Советы по тестированию

Поскольку Ozon не предоставляет тестовую среду для проверки функционала, реализованного продавцом, мы рекомендуем следующее:

  • Используйте авторизованные телефонные номера ваших внутренних сотрудников при их согласии для создания заказа.
  • Убедитесь, что у вас есть механизмы проверки мобильного телефона пользователя (например, код через SMS, аутентификация по ID в доверенных системах).
  • Не отображайте на своем сайте возможность доставки через Ozon до завершения тестирования.
  • Если вы не планируете тестировать заказ по полному циклу (включая доставку), отменяйте заказ сразу после создания, чтобы избежать комиссии за логистику.
  • Проверьте, что услуги Ozon Доставки доступны только на территории РФ.
