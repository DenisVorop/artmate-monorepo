# Общий механизм согласий

Цель: один домен `Consents`, без вызовов его бизнес-обработчиков из конкурсов и без общей транзакции сохранения согласия и заявки.

Согласовано пользователем: переиспользовать общие проверки; срок передавать параметром. Новый самостоятельный сервис не создаётся.

## Решение

- Расширить существующую очередь `apply_consent_decision_commands` и её обработчик командами регистрации документа, подготовки предложения и принятия согласий. Auth сохраняет собственное подтверждение личности; фиктивные операции входа не создаются.
- Внешним модулям доступны только контракт записи команд и опубликованные read-модели результатов, документов и подтверждений.
- Общие проверки решений, редакций и подтверждённой личности находятся внутри `Consents`.
- Конкурсы передают срок 15 лет; обработчик не содержит конкурсной политики.
- Подача фотографии сохраняется до подтверждения согласий. По результату команды конкурс своей транзакцией завершает заявку. Повтор и перезапуск процесса не теряют фотографию и не создают вторую заявку.
- `ContextualConsentService` удалить; оставить внутренние функции общего обработчика, без экспортируемого бизнес-сервиса.

## Результат проверки

- 146 сценариев Auth и существующих согласий прошли на PostgreSQL в отдельной схеме.
- 37 сценариев конкурсов/призов прошли после перевода на команды; окончательный набор из 32 проверок на чистой миграции включает новые сценарии восстановления, независимого сохранения конкурса, сроки, повторы и проверки доказательств.
- 22 проверки миграций и неизменяемости доказательств прошли, включая новый запрет изменения поданной фотографии и терминального результата подачи.
- Общий обработчик проверен на объекте произвольного домена без создания конкурса: сроки 1, 7 и 15 лет, повторная обработка, отказ по чужому предложению и снятой редакции, сохранение исходных байтов формы.
- API: `check-types:test`, полный `lint` и `build` прошли. Сайт: `check-types` и полный `lint` прошли.
- Полный собранный API инициализирован на тестовой базе и штатно завершён, без открытия HTTP-порта.
- Архитектурная сверка: у конкурсов нет импорта бизнес-обработчика Consents, обращения к его внутренним таблицам или общей транзакции подтверждения и заявки. `ContextualConsentService` удалён.
- Миграция применена к локальной `artmate_api`; production не менялся. Отдельная тестовая база удалена после проверок.
