# Подтверждённая почта — упрощение входа

По запросу пользователя удалена специальная ветка для аккаунтов с автоматически проставленным подтверждением почты. Production-проверка не обнаружила таких пользователей; агрегаты и запрос сохранены в verification/verified-email-reuse. Новых обращений к production при исправлении кода не было.

Текущий сценарий: почта и пароль верны, почта уже подтверждена → недостающие согласия → «Продолжить» → вход. Все согласия действуют → сразу completion. Рекламная галочка не требует повторного кода или отдельного письма.

Users публикует прежний emailVerifiedAt вместе с email и userId. Auth сохраняет подтверждение с исходной датой как RECORDED_EMAIL_VERIFICATION; текущая проверка пароля фиксируется отдельно. Повторный вход переиспользует тот же факт. Подписка появляется только после отдельного согласия, сам вход её не создаёт.

Из схемы, контрактов и неприменённой миграции удалены nullable identityFactId, добавочные FK/null-safe guards и исключение для входа без подтверждения. Восстановлены обязательный proof и составные FK. В текущем плане нет ветки миграционных аккаунтов, нового экрана кода для рекламы или адаптации downstream contracts для этой группы.

Архитектура сохранена: Auth читает опубликованный контракт Users и пишет только своё состояние; профиль, заказы и рекламную подписку password handler не меняет. UI, уведомления и существующая парольная политика не менялись. Полная новая выдача сессии после согласий остаётся этапом 5; подключение UI — своим этапом.

Проверки: 28 native PostgreSQL/HTTP tests и 114 адресных API tests прошли. В native тесте рекламное согласие успешно сохранено с прежним подтверждением пользователя; для его email не создано ни одного challenge и не отправлено новое письмо. Чужой proof отклоняется. API build/check-types/check-types:test/lint и Prisma validate прошли, diff check чистый. Полный API suite и frontend проверки заново не запускались: frontend не изменён.

Логи — [verification/verified-email-reuse/summary.json](./verification/verified-email-reuse/summary.json). Тестовая PostgreSQL остановлена, порт 62311 освобождён. Рабочая БД не изменена, миграции на неё не применялись. Коммит и переход к 3b не выполнялись.
