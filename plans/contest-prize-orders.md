# Выдача альбомных призов и бесплатный заказ

## Решения

- Победители равноправны. Администратор задаёт одинаковый альбомный приз каждому: количество разных альбомов и доступный список.
- Право на приз принадлежит домену заказов: он читает опубликованный результат конкурса и сохраняет собственное право, уникальное по победителю. Конкурсы не вызывают оформление заказа и не меняют его таблицы.
- Выдача повторяется безопасно по расписанию и при чтении личных призов; существующие итоги также обрабатываются после настройки альбомов.
- До первой заявки состав приза редактируется. Для старых конкурсов без настройки допускается однократное заполнение; после заполнения и при наличии заявок/итогов состав неизменяем.
- Бесплатный заказ принадлежит тому же домену, что и право: блокировка права и уникальная связь с заказом фиксируют получение одной транзакцией. Корзина покупателя не используется.
- Только Ozon. Адрес проверяет существующий серверный адаптер доставки. Покупатель платит 0 ₽; покрытая Artmate доставка учитывается отдельно. Платёж не требуется, банковские события и финансовые начисления не создаются.
- Используются реальные товары и реальные права. Временные UI-примеры удаляются. Альбомные призы подключены; персональные промокоды реализованы отдельным этапом в `plans/contest-promo-prizes.md`.
- Автоматический возврат права после отмены не вводится без отдельного решения; повтор запроса возвращает уже созданный заказ.
- После оформления и по ссылке «Посмотреть заказ» открываются `/account/orders` — «Мои заказы». Отдельное подтверждение призового заказа удалено. Оформленный приз при повторном открытии также ведёт в заказы.
- В карточках доступных и использованных призов ссылка на конкурс — кубок и название, без рамки, фона, стрелки и искр. В блоке «Победители» личных кнопок приза и заказа нет; получение приза и просмотр заказа доступны в личном кабинете.

## План и состояние

- [x] Схема, миграция, настройка альбомов в админке.
- [x] Однократная выдача из опубликованных итогов и личный API.
- [x] Бесплатный заказ, проверка товаров/ПВЗ, защита от повторов, статусы без оплаты.
- [x] Сайт: настоящие призы, выбор и оформление, история и ссылка на заказ.
- [x] Проверки API/PostgreSQL, платный checkout, типы/lint/build, локальная E2E без внешней отправки.

Локальная исходная база и production не меняются. Миграции и тестовые записи — только в выделенных test/UI-базах.

## Проверки

- PostgreSQL + HTTP: 24 проверки конкурсов/выдачи, включая конкурентное оформление, права доступа, CSRF, ошибку доставки, наличие товара, платёжные инварианты и завершение доставки без финансовых начислений.
- Регрессия платных заказов: 85 серверных проверок. Checkout сайта: 88 проверок и 3 проверки призовых форм. Админка: 162 проверки и 5 проверок формы конкурса.
- Сборки API, сайта и админки, типы и lint проверены.
- Локальная E2E: настройка существующего тестового конкурса через админку → выдача победителю → выбор реального товара → выбор тестового ПВЗ на карте → согласия → заказ на 0 ₽ → перезагрузка → история → заказ в админке и личный переход из результатов.
- В UI-базе оставлен заказ `prize_3e303fea9f8040d0873625fe11` для просмотра. JSON проверки не содержит контактных данных.
- Ozon проверялся в штатном mock-режиме локального API; внешние отправления, платежи и production не менялись. Для реальной отправки используется существующая привязка отправления Ozon в админке.
